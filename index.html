Roteiros de viagem

Pra onde a gente vai?

Escolham uma viagem no mapa ou na lista. Cada roteiro abre com o passo a passo do dia, horários e atalhos do Google Maps.

Toquem num pino para abrir o roteiro. Aproximem o mapa para ver as paradas numeradas.
➕ Como adicionar uma viagem nova
Todas as viagens e paradas ficam no arquivo viagens.js, dentro do próprio site. Para criar uma viagem nova, copiem o bloco de uma viagem, colem depois de uma vírgula e troquem nome, datas e paradas. Um roteiro sem o campo pagina ganha uma página automática (mapa, checklist e botões do Maps) em roteiro/?id=…. Para um roteiro muito personalizado, criem uma pasta com um index.html próprio e coloquem pagina: "pasta/".
Os dados de cada roteiro ficam salvos no próprio código do site. As marcações de "feito" ficam no celular de quem marcou.
